⚙️ CONFIGURATION

Edit config.json to customize:

```json
{
  "server": {
    "port": 8000,              // API port
    "ui_port": 3000            // Web UI port
  },
  "sensing": {
    "mode": "real-time",
    "simulation_enabled": true,     // Use built-in data if no hardware
    "simulation_frame_rate": 30     // Frames per second
  },
  "features": {
    "presence_detection": true,
    "vital_signs": true,
    "activity_recognition": true,
    "fall_detection": true,
    "multi_room_tracking": true
  },
  "calibration": {
    "auto_calibrate": true,
    "calibration_duration_seconds": 30
  }
}
```

Restart app for changes to take effect.
