ESP32-S3 CSI node boot and runtime log for docs/tutorials/esp32-s3-csi-quickstart.md

Captured 2026-10-22 on the guide author's Windows 11 host over a CH343 USB
serial bridge at COM5, 115200 baud. The node was reset through the USB serial
adapter (RTS pulse) and the console was read from the first byte of the ROM
banner; nothing was written to the node.

Board: ESP32-S3 (QFN56 rev 0.2), 16 MB flash, mxic SPI flash in DIO mode.
Firmware: 0.8.15, built Oct 21 2026 22:01:09 with ESP-IDF v5.4.

The node was provisioned with target_ip=192.168.0.57, an address that is not
present on the LAN, so every UDP send failed and the CSI yield was throttled
by the adaptive controller. That is the failure this guide documents.

Redactions: the home network SSID, the AP BSSID and the node's own MAC address
are replaced with placeholders. The private LAN addresses are kept because the
diagnostic depends on them.
