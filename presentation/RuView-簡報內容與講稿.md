## 投影片 1 — 研究動機:為什麼用 WiFi 感測人體?

**投影片要點**
- **痛點:現有人體感測方案都有硬傷**
  - 攝影機:有隱私疑慮(GDPR/HIPAA)、需光線、無法穿牆、每點 $200–$2000
  - 穿戴裝置:需配戴、要充電、長者/病患配合度低
  - 紅外/PIR:只能測「有沒有動」,無法測呼吸、姿態
- **機會:WiFi 電波無所不在**
  - 人移動、呼吸,甚至靜止,都會擾動電波 → 可量測
  - 用一台 Raspberry Pi 4 + nexmon_csi 讀取「通道狀態資訊 (CSI)」即可
- **價值主張**
  - 🔒 無影像,天生規避影像隱私法規
  - 🧱 穿牆、穿家具、穿瓦礫;🌙 全黑可用
  - 💰 一台樹莓派約 $50,遠低於攝影機 $200–2000

🎤 **講稿**
> 先談動機。我們要解決的問題是:「如何在不侵犯隱私的前提下,持續、可靠地感測室內的人?」現有的方案各有硬傷——攝影機效果好,但有嚴重的隱私問題,在臥室、浴室、醫院、長照機構根本不能裝,而且它怕黑、不能穿牆,一個點位要兩百到兩千美金;穿戴裝置要使用者乖乖戴著、還要充電,對長者跟病人來說配合度很低;紅外感測器只能知道「有東西在動」,測不到呼吸,更別說姿態。
>
> 而我們的切入點是:WiFi 電波其實無所不在。當一個人在房間裡移動、甚至只是呼吸,他的身體都會反射、吸收、散射這些電波,在訊號上留下可以量測的擾動。我們只要用一台約五十美金的 Raspberry Pi 4,搭配 nexmon_csi,去讀取 WiFi 的「通道狀態資訊」,也就是 CSI,就能把這些擾動還原成有意義的資訊。這帶來三個關鍵價值:第一,完全沒有影像,天生就規避了影像類的隱私法規;第二,電波能穿牆、穿家具、甚至穿瓦礫,而且全黑也能用;第三,成本遠低於攝影機,而且 WiFi 本來就佈滿我們的生活空間。

- **平台亦相容**:ESP32-S3 · Intel 5300 · Atheros AR9580,並可擴展為多基地台 mesh(本實作採用單台 Pi 4)
- **部署成本**:單台 Raspberry Pi 4 約 $35–55

🎤 **講稿**
> 先看硬體。我們這次的實作裝置,是一台 Raspberry Pi 4。它最關鍵的地方,是內建的 Broadcom BCM43455c0 這顆 WiFi 晶片——透過 nexmon_csi 這個韌體修補,它可以在 monitor mode 下,直接擷取每一個子載波的複數 CSI。而且因為它是 802.11ac,最高可以到八十 MHz、最多兩百五十六個子載波,比 ESP32 的六十四個多了好幾倍,訊號解析度更高。

>
> 補充一下,我們的平台本身其實也相容 ESP32-S3、Intel 5300、Atheros 這些 CSI 來源,而且可以擴展成多節點的多基地台 mesh;但這次的實作,我們是用單台 Pi 4 來驗證整條核心管線。

## 投影片 4 — 2.1 軟硬體架構 (二):軟體 — 15 個 Rust Crate 的分層

**投影片要點**
- **分層架構(依依賴順序)**
```
基礎層   core(型別/CSI frame)· vitals · wifiscan · hardware(TDM/封包解析)
訊號/AI  signal(SOTA DSP + RuvSense 14 模組)· nn(ONNX/Candle)· ruvector(AI 骨幹)· train
應用層   mat(災難搜救)· wasm(瀏覽器)· sensing-server(Axum)· cli
```
- **關鍵技術棧**
  - 語言:Rust(主力)+ Python(PyO3 wheel,`pip install ruview`)
  - 推論後端:ONNX / PyTorch / **Candle**(三後端)
  - AI 骨幹:**RuVector v2.0.4**(attention、圖 min-cut、稀疏求解、時序壓縮)
  - 模型封裝:**RVF** 格式(單檔、Ed25519 簽章、漸進式載入、量化)
  - Server:Axum(REST :3000 / WebSocket :3001 / UDP :5005)
  - 整合:MQTT + Matter Bridge + 隱私模式(剝除心率/姿態,只留語意狀態)
- **效能成果**:記憶體 100 MB(vs Python 500 MB)、Docker 132 MB(vs 569 MB)

🎤 **講稿**
> 再看軟體。整個 Rust 程式碼庫由十五個模組(crate)組成,而且是嚴格分層的。最底層是核心型別跟 CSI 影格的定義、生命徵象、WiFi 掃描、還有負責跟 ESP32 講話、解析封包的硬體層;中間是訊號與 AI 層,包含我們的 SOTA 訊號處理、十四個多基地台感測模組、神經網路推論、以及叫做 RuVector 的 AI 骨幹跟訓練管線;最上層才是應用,像災難搜救工具、瀏覽器的 WASM 版、Axum 寫的感測伺服器,還有命令列工具。
>
> 技術棧的重點有幾個:主力語言是 Rust,但我們也提供 Python 的安裝包,一行 pip install 就能用;推論支援 ONNX、PyTorch 跟 Candle 三種後端;AI 骨幹用的是 RuVector,提供注意力機制、圖論的 min-cut、稀疏求解這些演算法;模型則打包成我們自訂的 RVF 格式,單一檔案、有數位簽章、可以分層漸進載入;伺服器用 Axum,同時開 REST、WebSocket 跟 UDP;對外還能接 MQTT 跟 Matter,而且有一個「隱私模式」,可以把心率、姿態這些敏感資料剝掉,只輸出像「有人在睡覺」這種語意狀態。
>
> 用 Rust 重寫帶來很實際的好處:整個系統的記憶體只用一百 MB,Python 版要五百 MB;Docker 映像檔從五百六十九 MB 壓到一百三十二 MB。

## 投影片 5 — 2.2 工作原理 (一):CSI 為何能「看見」人

**投影片要點**
- **CSI(通道狀態資訊)是什麼?**
  - WiFi 用 OFDM,把訊號拆成幾十個「子載波」
  - 每個子載波都記錄了振幅衰減 + 相位偏移(複數值)
  - 相較 RSSI 只有 1 個純量,CSI 有 56–256 個子載波 × 複數相位 → 資訊量大幾個數量級
- **人為什麼會擾動訊號?**
  - 人體是反射 / 吸收體,改變多重路徑傳播
  - 🫁 呼吸:胸腔位移 1–5 mm,頻率 0.1–0.5 Hz
  - 💓 心跳:體表位移僅 0.1–0.5 mm,頻率 0.8–2.0 Hz(更難)
- **挑戰**:商用晶片的原始相位含隨機硬體誤差(CFO/SFO)→ 必須先清理

🎤 **講稿**
> 接下來解釋背後的原理:為什麼 WiFi 訊號能「看見」人?關鍵在 CSI,也就是通道狀態資訊。現代 WiFi 用一種叫 OFDM 的技術,會把訊號拆成幾十個並行的「子載波」。CSI 記錄的,就是每一個子載波在從發射端傳到接收端的過程中,經歷了多少振幅衰減、多少相位偏移——它是一組複數值。對比之下,一般我們講的訊號強度 RSSI 只是一個數字,而 CSI 有五十六到一百九十二個子載波、每個還帶相位,資訊量大了好幾個數量級。
>
> 那為什麼人會擾動它?因為人體本身就是一個反射跟吸收電波的物體。當你在房間裡,電波會經由很多條路徑——直射的、從牆壁地板反射的——疊加到接收端,而你的身體會改變這些路徑。具體來說,呼吸時胸腔大概起伏一到五毫米,頻率是零點一到零點五赫茲;心跳更微弱,體表只動零點一到零點五毫米,頻率零點八到兩赫茲,所以心率比呼吸難非常多。
>
> 不過這裡有個工程上的大挑戰:便宜的商用晶片,它讀到的原始相位裡混了很多隨機的硬體誤差,像載波頻率偏移、取樣偏移,每一個封包都不一樣。所以我們不能直接用,必須先做訊號清理。

## 投影片 6 — 2.2 工作原理 (二):端到端訊號處理流程

**投影片要點**
- **資料流**
```
WiFi 電波 → 人體散射 → Raspberry Pi 4 用 nexmon 擷取 CSI
  → rvCSI 正規化(逐子載波複數 CSI)
  → 品質相干閘 Coherence Gate(Accept / 預測 / 拒絕)
  → 訊號處理(6 大 SOTA 演算法)
  → 對比學習模型(Candle 本地推論)
  → 輸出:姿態 + 呼吸 + 心率 + 房間指紋
```
- **6 大 SOTA 訊號處理演算法**(各對應經典論文)

| 演算法 | 作用 | 出處 |
|--------|------|------|
| 共軛相乘 (CSI Ratio) | 消除 CFO/SFO 硬體相位誤差 | SpotFi |
| Hampel 濾波 | 抗 50% 污染的離群值移除 | WiDance |
| Fresnel 區模型 | 依幾何預測呼吸訊號 | FarSense |
| STFT 頻譜圖 | 時頻分析(呼吸帶 / 走路帶) | — |
| 子載波敏感度選擇 | 選最佳子載波,SNR +6–10 dB | WiDance |
| 身體速度分布 (BVP) | 域獨立、跨環境辨識基礎 | Widar 3.0 |

- **輕量管線**:全在單台 Pi 4 上即時完成(nexmon 擷取 → rvCSI → 訊號處理 → Candle 推論),**無多節點融合開銷**

🎤 **講稿**
> 這一頁是整個系統的核心流程。從左到右:WiFi 電波經過人體散射後,由我們的 Raspberry Pi 4 用 nexmon 擷取下 CSI;接著 rvCSI 做正規化;然後經過一個「品質相干閘」,它會判斷這筆量測能不能信任,決定要接受、只用來預測、還是拒絕;通過之後送進六個 SOTA 演算法做訊號處理,最後由 Candle 在這台 Pi 上做本地推論,輸出姿態、呼吸、心率跟房間指紋。
>
> 訊號處理這一塊,我們用了六個業界最先進的演算法,而且每一個都對應到一篇經典論文。第一個是共軛相乘,把兩根天線的訊號相乘,剛好可以把前面提到的硬體相位誤差消掉,這來自 SpotFi;第二個 Hampel 濾波,用來移除離群值,即使一半的資料被污染都還能運作;第三個是 Fresnel 區模型,它根據發射端、人體、接收端的幾何關係,去預測呼吸應該出現在訊號的哪裡,來自 FarSense;再來是短時傅立葉的頻譜圖、子載波敏感度選擇——它能讓訊噪比提升六到十 dB;最後是身體速度分布 BVP,這個特性很重要,因為它跟房間佈局無關,是跨環境辨識的基礎,來自知名的 Widar 3.0。
>
> 而且因為整條管線都在「同一台」樹莓派上完成,沒有多節點之間傳輸跟融合的額外開銷,所以即使在 Pi 4 這種邊緣裝置上,也能即時運作。

  - 確定性合成 CSI(seed=42,1,000 幀)用於 SHA-256 可重現性驗證
- **資料前處理**:逐幀 z-score、子載波統一內插到 56、相位淨化

🎤 **講稿**
> 第二點三節談資料集怎麼來。我們有三個來源。第一是公開資料集,用來做模型的初始訓練。主要用的是 MM-Fi,這是 NeurIPS 2023 釋出、目前最大的 WiFi CSI 加姿態資料集,有四十個受試者、二十七種動作、大約三十二萬幀,而且它是多模態的,同時有 CSI、毫米波、光達跟 RGB-D,標註用的是十七個 COCO 關鍵點加上 DensePose 的表面座標;次要的是 Wi-Pose,它的三乘三天線設定剛好跟我們的 ESP32 mesh 對得上。
>
> 第二是我們自建的資料,這是整個系統最有特色的地方——「相機 ground-truth 配對採集」。我們在收集訓練資料時,用一台筆電的攝影機,透過 MediaPipe 偵測出人體的關鍵點,把它當作「正確答案」,也就是教師訊號,去教 WiFi 模型;CSI 跟相機用一個兩百毫秒的時間窗對齊。重點是:攝影機只在「收集訓練資料」這個階段出現,系統真正部署時是完全沒有攝影機的。而且為了隱私,原始影像永遠不存檔,只留下關節的座標數字。
>
> 第三是自監督跟合成資料。我們做過一次整夜的真實採集,得到六萬多個樣本,衍生出六十一萬組對比學習的三元組;另外還有一套用固定亂數種子產生的合成 CSI,專門拿來做可重現性的雜湊驗證。所有資料在進模型前,都會做逐幀正規化、把子載波數統一內插到五十六、還有相位淨化。

## 投影片 8 — 2.4 模型選用與訓練 (一):模型架構

**投影片要點**
- **核心:對比式 CSI 編碼器(AETHER,ADR-024)**
  - 共享 Backbone:CSI(56)→ Transformer + 4-head 交叉注意力 + 圖神經網路(GNN)
  - 雙輸出頭(一次前向、同時產生):
    - 🦴 **姿態頭** → 17 個關鍵點 (x, y, z, 信心值)
    - 🧬 **嵌入頭** → 128 維環境指紋向量(L2 正規化)
  - 參數量:約 **55,000**(220 KB / INT8 僅 55 KB)
- **姿態模型(WiFlow)**:TCN + 軸向注意力 + 姿態解碼器,1.8M 參數,4-bit 量化僅 881 KB
- **為何這樣設計**
  - 128 維是 SimCLR / CLIP 的標準嵌入維度
  - 共享 backbone:一次運算同時得到「姿態」+「指紋」(<2 ms)
  - 遵循 CMU「DensePose From WiFi」(arXiv:2301.00250)的架構家族

🎤 **講稿**
> 接著是模型。我們的核心模型叫 AETHER,是一個對比式的 CSI 編碼器。它的設計很巧妙:輸入五十六維的 CSI 之後,先經過一個共享的骨幹網路,裡面有 Transformer、四頭的交叉注意力、還有圖神經網路;然後分成兩個輸出頭,在「同一次前向運算」裡同時產生兩種東西——一個是姿態頭,輸出十七個人體關鍵點的三維座標跟信心值;另一個是嵌入頭,輸出一個一百二十八維的「環境指紋」向量。整個模型只有大約五萬五千個參數,量化成八位元之後只佔五十五 KB。
>
> 負責全身姿態的 WiFlow 模型,用的是時序卷積網路加上軸向注意力,一百八十萬個參數,做完四位元量化也才八百八十一 KB。
>
> 為什麼這樣設計?第一,一百二十八維是 SimCLR、CLIP 這些主流對比學習模型的標準嵌入維度;第二,用共享骨幹的好處是,一次運算就能同時拿到「姿態」跟「指紋」,只要不到兩毫秒;第三,整個架構遵循 CMU 在 2023 年發表的「DensePose From WiFi」這篇開創性論文的設計家族,有紮實的學理基礎。

## 投影片 9 — 2.4 模型選用與訓練 (二):訓練策略與邊緣量化

**投影片要點**
- **三種訓練模式**

| 模式 | 需要的資料 | 得到的能力 |
|------|-----------|-----------|
| 自監督對比學習 | 僅原始 WiFi | 懂 CSI 結構的 backbone |
| 監督式微調 | WiFi + 姿態標籤 | 全身姿態 + 指紋 |
| 跨模態 | WiFi + 相機 | 與視覺對齊的指紋 |

- **訓練技巧**:Hard-negative mining(只挑最難的負樣本)+ 課程學習(由易到難)
- **訓練工具與速度**
  - Candle + CUDA(RTX 5080):**400 epochs / 2.1 秒**
  - ruvllm(Mac M4 Pro):**從零訓練 84 秒**、線上適應新房間 <30 秒
- **邊緣量化(縮小模型,載入更快)**

| 版本 | 大小 | 用途 |
|------|------|------|
| safetensors (FP32) | 48 KB | 訓練 / 評估 |
| q8 (8-bit) | 16 KB | Pi Zero 高品質 |
| **q4 (4-bit) ⭐** | **8 KB** | **邊緣推論首選** |
| q2 (2-bit) | 4 KB | 極限記憶體 |

- **環境適應**:每房間僅 **1,792 參數**的 MicroLoRA(較重訓減 93%)+ EWC++ 防遺忘
- **預訓練規模**:12.2M 訓練步 / 60K 幀 / 610K 三元組(已發布於 Hugging Face)

🎤 **講稿**
> 訓練策略上,我們支援三種模式:只有原始 WiFi 資料時,做自監督對比學習,讓模型先學會 CSI 的結構;有姿態標籤時,做監督式微調,得到完整的姿態能力;有配對的相機資料時,做跨模態訓練,讓 WiFi 的指紋跟視覺對齊。訓練時用了兩個技巧:一個是 hard-negative mining,專挑最容易混淆的負樣本來訓練,效率更高;另一個是課程學習,從簡單的站姿,慢慢進到複雜的全身動作。
>
> 訓練速度其實很快:用 Candle 加 CUDA 在一張 RTX 5080 上,跑四百個 epoch 只要兩點一秒;用 ruvllm 在 Mac M4 Pro 上,從零訓練一個模型只要八十四秒,而且換到一個新房間,線上適應不到三十秒就好。
>
> 為了讓模型在邊緣裝置上更輕量、載入更快,我們做了多級量化。全精度是四十八 KB,八位元十六 KB,我們推薦的四位元版本只有八 KB;最極限的兩位元只要四 KB。換新環境時,我們不需要重訓整個模型,只要為那個房間訓練一個一千七百九十二個參數的小小 LoRA 模組,比重訓省了九成三的成本,再搭配 EWC 演算法防止它忘掉舊知識。我們已經把一個用一千兩百二十萬步、六萬幀、六十一萬組三元組訓練出來的預訓練模型,公開發布在 Hugging Face 上。

## 口語短版講稿(提示卡)— 上台瞄一眼用,不照唸

> 這份「精簡口語短版」已同步嵌入 `RuView-簡報.pptx` 的每頁「備忘稿 (speaker notes)」。上台時看投影片下方的備忘稿即可。

**S0 封面** — 大家好,今天報告 RuView,用 WiFi 訊號看見人。不用攝影機、不用穿戴、能穿牆,靠 WiFi 電波加物理。

**S1 研究動機** — 問題:隱私下持續感測室內人。攝影機怕黑/不能穿牆/貴/隱私;穿戴要戴要充電;PIR 只知有沒有動。→ WiFi 無所不在,人一動就擾動電波,一台 ~$50 樹莓派 + nexmon 讀 CSI 即可。三價值:無影像規避法規、穿牆全黑、成本遠低於攝影機。

**S2 系統簡介** — 一句話:普通 WiFi 變非接觸感測器。五能力:存在/人數、呼吸心率、姿態/跌倒、室內地圖、睡眠。全邊緣、離線可用、可接 Apple/Google Home。雙碼庫:Python 原型 + Rust 主力快 810×。

**S3 硬體** — 實作裝置是一台 Raspberry Pi 4。內建 BCM43455c0 WiFi 晶片,用 nexmon_csi 直接擷取逐子載波複數 CSI,802.11ac 最高 80 MHz / 256 子載波(ESP32 才 64)。重點:擷取+推論都在同一台 Pi 上跑完(nexmon→rvCSI→訊號處理→Candle 推論),不用額外節點或伺服器,單機約 $35–55。平台也相容 ESP32/Intel/Atheros、可擴展多基地台 mesh,本次用單台 Pi 4。

**S4 軟體** — 15 個 Rust crate 三層:基礎(core/硬體)→ 訊號 AI(DSP/RuvSense/RuVector/訓練)→ 應用(災難/WASM/server/CLI)。Rust+Python、Candle、RVF 簽章模型、Axum、MQTT/Matter+隱私模式。Rust 讓記憶體 100 MB、Docker 132 MB。

**S5 CSI 原理** — CSI:OFDM 拆數十子載波,每個記振幅+相位(複數),比 RSSI 多幾個數量級。人是反射體改變多徑:呼吸 1–5 mm、心跳 0.1–0.5 mm 更難。挑戰:商用晶片原始相位有硬體誤差,要先清理。

**S6 流程** — 電波→人體散射→Pi 4 用 nexmon 擷取 CSI→rvCSI 正規化→品質相干閘把關→6 大演算法→Candle 推論→輸出。六演算法各對應論文:共軛相乘(SpotFi)、Hampel、Fresnel(FarSense)、頻譜圖、子載波選擇 +6–10 dB、BVP(Widar 3.0)。全在單台 Pi 4 即時跑完,無多節點融合開銷。

**S7 資料集** — 三來源。公開:MM-Fi(40 人×27 動作×32 萬幀,NeurIPS23)、Wi-Pose。自建:webcam→MediaPipe→17 COCO 當教師,200 ms 對齊,相機只訓練不部署,影像不存只留座標。自監督:整夜 6 萬樣本→61 萬三元組。前處理:正規化、子載波內插到 56。

**S8 模型架構** — AETHER 對比編碼器:CSI(56)→共享骨幹(Transformer+交叉注意力+GNN)→雙頭一次出:姿態 17 點 + 嵌入 128 維指紋。僅 5.5 萬參數、INT8 55 KB。姿態 WiFlow 1.8M→4-bit 881 KB。設計:128 維是 CLIP 標準、共享骨幹 <2 ms、源自 CMU DensePose-From-WiFi。

**S9 訓練** — 三模式:自監督對比/監督微調/跨模態。技巧:hard-negative+課程學習。速度:RTX5080 400 epoch 2.1 秒、M4 從零 84 秒、換房間 <30 秒。量化 48 KB→8 KB(4-bit,適合邊緣)。換環境只訓 1792 參數 LoRA(省 93%)+ EWC 防遺忘。預訓練 1220 萬步已上 HuggingFace。

**S10 成果展示** — 線上 Demo:Observatory 即時骨架、雙模態融合、3D 點雲、5 個 three.js。一行 Docker 30 秒上手。現場可演:即時骨架、呼吸心率、房間掃描、跌倒、穿牆。等下播錄屏。

**S11 已驗證指標** — 全部實測:存在 100%、計數 24/24、推論 0.008 ms / 16.4 萬嵌入·秒、管線快 810×、+51.6%、骨架 0 違反、8 KB、1463 測試全過。語意 F1 浴室 0.98、活動 0.95。誠實:姿態 PCK@20 目前 3%(目標 35%),瓶頸是資料量不是架構;早期 92.9% 是誇大已更正,我用真數字。

**S12 比較** — vs 攝影機:成本 $0–9 vs $200–2000、無影像規避法規、穿牆全黑、多人。文獻基準(CMU 同架構):同佈局 WiFi AP@50 87.2 逼近相機 94.4;跨佈局掉到 27.3→泛化難題,對應 MERIDIAN。Rust 快 810×、Pi5 推論 8.4 ms。

**S13 結論** — 證明:一台 Raspberry Pi 4 做非接觸/穿牆/隱私感測,完整端到端。已驗證:存在 100%、16 萬嵌入·秒、8 KB、1463 測試。工程嚴謹:可重現驗證+見證鏈、誠實區分實測/目標。未來:補資料把姿態 3%→35%、MERIDIAN 泛化、樹莓派端推論優化。一句話:讓空間感知變成一台樹莓派、隱私優先、隨處部署。謝謝。

**S14 源碼** — 源碼 GitHub ruvnet/RuView;套件 PyPI/crates.io/npm/Docker 都能裝;模型在 HuggingFace;測試資料:自帶確定性 proof + 公開 MM-Fi、Wi-Pose;邊緣 runtime rvCSI。

**S15 文檔** — 文檔很完整:User/Build Guide、96 份 ADR、8 個 DDD 模型、線上 Demo、HA+Matter 整合、Cognitum Seed、Docker Hub。

**S16 論文** — 核心:DensePose From WiFi、MM-Fi、Person-in-WiFi 3D。訊號:SpotFi、FarSense、Widar3.0。學習:SimCLR、VICReg、LoRA、EWC、HNSW。報告結束,謝謝,進入提問。
