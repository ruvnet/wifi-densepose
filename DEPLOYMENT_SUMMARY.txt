🛠️ TROUBLESHOOTING

"Python not found"
  → Install Python 3.9+ from python.org
  → Check "Add to PATH" during install
  → Restart PowerShell

"Cargo not found"
  → Install Rust from rustup.rs
  → Run installer and follow prompts
  → Restart PowerShell

"Port 8000 already in use"
  → netstat -ano | findstr :8000
  → taskkill /PID <PID> /F
  → Or change port in config.json

"Build takes 10+ minutes"
  → First build compiles 15 Rust crates
  → Subsequent builds are 30 seconds
  → This is normal!

💻 EXAMPLE USAGE

Python integration:
  ```python
  import requests
  response = requests.get('http://localhost:8000/api/v1/sensors')
  print(response.json())
  ```

JavaScript WebSocket:
  ```javascript
  const ws = new WebSocket('ws://localhost:8000/api/v1/stream');
  ws.onmessage = (e) => {
    const data = JSON.parse(e.data);
    console.log(data.vitals.breathing_bpm);
  };
  ```

  ```yaml
  sensor:
    - platform: mqtt
      topic: "ruview/living_room/presence"
  ```
