RuView sensing-server evidence for docs/tutorials/esp32-s3-csi-quickstart.md

Captured 2026-10-22 on the guide author's Windows 11 host, Ethernet 192.168.0.45/24,
gateway 192.168.0.1, with one ESP32-S3 node (firmware 0.8.15) on the same LAN at
192.168.0.107. The node was provisioned with target_ip=192.168.0.57, an address
that is not present on the LAN, so no CSI frame ever reached this host.

The server binary was built from this repository at main (fcf3e93f):
  cargo build -p wifi-densepose-sensing-server --no-default-features

Run 1 shows the refusal to serve the API on a routable address without a token.
Run 2 shows the UDP data plane widening to 0.0.0.0 under the ADR-296 guard, and
the server state when no frame has ever arrived.
