❌ TROUBLESHOOTING (If Something Fails)

"Python not found"
  → Install: https://www.python.org/
  → Check: "Add Python to PATH" in installer
  → Restart PowerShell

"Rust not found"
  → Install: https://rustup.rs/
  → Restart PowerShell after install

"Build takes too long"
  → Normal! First build: 5-10 minutes
  → Next builds: 30 seconds
  → Just wait, it's compiling 15 Rust crates

"Port 8000 already in use"
  → In PowerShell: taskkill /F /IM python.exe
  → Then restart setup

"Dashboard won't load"
  → Check: curl http://localhost:3000
  → Check Windows Firewall
  → Allow python.exe through firewall
