# RuView ESP32 firmware 0.8.15 prerelease

Firmware 0.8.15 improves CSI processing and remote configuration recovery for
ESP32-S3 and ESP32-C6 nodes.

## Changes

- S3 STBC frames now contribute their bounded CSI prefix to edge processing
  instead of being discarded, preserving input for vitals and feature output.
- Gateway self-ping waits are capped to one probe interval. AP-specific ICMP
  airtime remains a deployment factor; `scripts/csi-udp-poke.py` provides a
  bounded private-LAN traffic source when CSI traffic is otherwise sparse.
- USB serial/JTAG onboarding prepares or reuses the IDF 6 driver and reports
  setup failures.
- The config API validates complete requests before writing and retains a
  durable rollback bank across failed writes and recovery attempts.
- Rust dependencies were updated for current Wasmtime and WebPKI advisories;
  the audit policy retains narrowly documented ignores for ZIP extraction
  advisories whose vulnerable extraction APIs are not used by the workspace.

## Validation

- Firmware host suite passed, including production-code STBC, self-ping,
  configuration rules, and write-through NVS rollback fault injection.
- ESP32-C6 firmware built with ESP-IDF 6.0.2 and fits the 4 MB partition map.
- The attached ESP32-C6 was observed on the LAN running firmware 0.8.14.
  Thirty-second paired captures recorded about 29 CSI packets/s in baseline
  and with bounded host traffic. The board was not flashed with 0.8.15 because
  a complete flash backup could not be obtained.
- This prerelease has no new physical-board firmware qualification or sensing
  accuracy claim. See the [candidate validation record](../validation/2026-10-20-esp32-csi-input-release-candidate.md).
