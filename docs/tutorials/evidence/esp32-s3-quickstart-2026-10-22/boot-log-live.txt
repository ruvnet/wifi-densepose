ESP32-S3 CSI node boot log with a live server on the same LAN

Captured 2026-10-22 on the guide author's Windows 11 host over a CH343 USB
serial bridge at COM5, 115200 baud. The sensing server was already running
and bound to 0.0.0.0:5005 with the ADR-296 source allowlist open to this node,
so the node's frames reached it from the first frame after boot.

The node was reset through the USB serial adapter (RTS pulse) and the console
was read from the first byte of the ROM banner. Nothing was written to the
node during this capture.

Board: ESP32-S3 (QFN56 rev 0.2), 16 MB flash, firmware 0.8.15.

The target_ip in this capture is the server host's own address, reached with
the bounded serial onboarding protocol that firmware 0.8.15 exposes:

  RUVIEW_HELLO_V1 <nonce>
  RUVIEW_CONFIG_V1 <nonce> 1 <target_ip> 5005 KEEP KEEP

KEEP KEEP leaves the WiFi credentials and the OTA key untouched. The protocol
needs no PSK and no reflash, which is why it is the path this guide
recommends over a USB re-provision.

Redactions: the home network SSID, the AP BSSID and the node's own MAC
address are replaced with placeholders. The private LAN addresses are kept
because the diagnostic depends on them.
