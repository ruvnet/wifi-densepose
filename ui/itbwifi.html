Technologie

Comment ça marche

Pas de magie. Juste de la physique. Votre WiFi rebondit sur les corps humains — nous lisons ces micro-variations pour reconstituer ce qui se passe dans la pièce.

ÉTAPE 01
📡

Le signal WiFi existe déjà

Votre box émet des ondes radio en permanence. Ces ondes traversent les murs et rebondissent sur tout — y compris les humains.

ÉTAPE 02
🔬

On lit les perturbations

Un capteur ESP32 à 9€ mesure comment le signal est modifié (CSI). Chaque mouvement, chaque respiration crée une signature unique.

ÉTAPE 03
🧠

L'IA reconstitue la scène

Notre modèle de deep learning transforme ces données radio en squelette 3D avec 17 points de corps, en temps réel.

ÉTAPE 04
⚡

L'API vous donne les données

Présence, posture, respiration, rythme cardiaque — tout est disponible via REST ou WebSocket, intégrable en quelques lignes.
